# brand-system.md — Бренд-система demosite

> Скилл `demosite` строит автономные премиальные РУ-сайты-витрины. Перед тем как
> генерировать дизайн, копирайт и картинки, нужно создать **правдоподобный бренд**:
> название, слоган и векторный логотип. Этот документ описывает, как это делать так,
> чтобы сайт выглядел как настоящий бизнес, а не как AI-демо. Источники:
> `~/.agents/skills/brandkit/SKILL.md` (принципы фирстиля и логотипа),
> `scripts/gen_logo.py` (наш SVG-генератор), `references/pipeline.md` (контракт `site.json`).

Базовый принцип из brandkit: **бренд — это не украшение, а аргумент, почему бизнес
существует**. Даже для витрины название и лого должны выглядеть «отобранными ресёрчем
и редукцией», а не сгенерированными случайно. Всё детерминировано по домену/seed, чтобы
два разных сайта не были похожи (см. `anti-fingerprint.md`).

## 1. Генерация РУ-названия из домена + ниши

На входе — домен (например `dental-lux.ru`) и ниша (`dental`). На выходе —
русское отображаемое имя бренда. Алгоритм: разобрать домен, по нише подобрать
паттерн, собрать имя, прогнать через банлист.

### 1.1. Разбор домена
1. Отбросить TLD (`.ru`, `.рф`, `.москва`, `.com`).
2. Разбить основу по `-`, `_`, цифрам на токены: `dental-lux` → `[dental, lux]`.
3. Каждый токен классифицировать:
   - **транслит русского слова** (`stroy`→строй, `zub`→зуб, `pravo`→право) — раскрыть в РУ;
   - **латинский премиум-суффикс** (`lux`, `prime`, `plus`, `med`, `dent`, `art`,
     `pro` — осторожно) — оставить капитализированным латиницей-в-кириллице
     (`lux`→«Люкс», `prime`→«Прайм», `med`→«Мед»);
   - **гео** (`msk`, `moscow`, `spb`, `kazan`) — раскрыть в город/регион;
   - **имя/фамилия** (`sokolov`, `ivanov`) — оставить как фамилию.
4. Собрать читаемое имя из 1–2 значимых частей. Падежи и пробелы — по-русски.

`dental-lux.ru` → токены `[dental(=зуб/стом), lux(=люкс)]` → **«Дентал Люкс»**
(`dental` оставляем фонетической калькой, как делает рынок, а не «Зубной Люкс»).

### 1.2. Паттерны построения имени
| Паттерн | Формула | Пример |
|---|---|---|
| **Гео + термин** | `<Город/Район> + <отраслевое слово>` | «Невский Стоматолог», «Замоскворечье Дент» |
| **Имя/фамилия + суффикс** | `<Фамилия> + (Групп/Бюро/Студия/Клиник)` | «Соколов и Партнёры», «Клиника Вересаева» |
| **Профессиональный термин** | прямое отраслевое слово + квалификатор | «Дентал Люкс», «ПраймДент», «АртСмайл» |
| **Метафора** | образ из мира клиента (без штампов) | «Белый Сад» (стом.), «Опора» (юр.), «Очаг» (ресторан) |

Выбор паттерна — по нише (см. 1.4) и детерминированно по seed домена, чтобы
для разных доменов получались разные паттерны.

### 1.3. АНТИ-СЛОП банлист (имя НЕ должно содержать)
Латинские клише: **Acme, Nexus, Quantum, Vortex, Apex, Zenith, Synergy, Stellar,
Vertex, Pixel, Hub, Lab(s)** (как самостоятельное имя), **Solutions, Systems** (в РУ-имени).

Русские штампы: **«Инновация», «ПрофЛидер», «ТопМастер», «МегаСтрой», «ЕвроРемонт»,
«ЛюксПрестиж», «Эксперт» (как имя), «Премиум» (как имя), «Гарант» (избито),
«Альфа/Бета/Омега + слово», «СуперСервис», «БестДент», «Голд+слово».**

Правило склейки: избегать слитных капс-композитов в стиле `СтройГрад`, если
по нише уместнее раздельное имя. Допустимы аккуратные композиты («ПраймДент»,
«АртСмайл»), но не более одного на бренд и без превосходных степеней внутри.

### 1.4. Хорошие РУ-примеры по нишам (8–10)
| Ниша | Бренд | Паттерн |
|---|---|---|
| dental | **Дентал Люкс** | проф. термин + люкс-квалификатор |
| clinic | **Клиника Вересаева** | имя + тип учреждения |
| law | **Соколов и Партнёры** | фамилия + суффикс (классика юр.) |
| construction | **Каменный Двор** | метафора надёжности |
| restaurant | **Очаг** | метафора-атмосфера (одно слово) |
| beauty | **Белая Лилия** | метафора-эстетика |
| autoservice | **Гаражный Квартал** | гео-метафора |
| fitness | **Атлет на Тверской** | термин + гео |
| realestate | **Невский Метраж** | гео + отраслевое слово |
| b2b/logistics | **Линия Поставок** | проф. метафора процесса |

Каждое имя проходит тест: «звучит ли как вывеска, мимо которой можно пройти в Москве?»

## 2. Слоган (tagline)

Короткий (3–6 слов), конкретный, по-русски, без буллшита. Формулирует **обещание
или результат**, а не свойство. По духу brandkit: «short and specific», не
«buzzword soup».

Запрещено: «инновационные решения», «качество и надёжность», «ваш надёжный партнёр»,
«широкий спектр услуг», «индивидуальный подход» (штамп), «лидер рынка».

Хорошие формулы: *результат* («Улыбка, которой доверяют»), *забота* («Лечим бережно,
объясняем понятно»), *уверенность через конкретику* («Сдаём в срок. Без переплат»).

### 6 примеров
| Ниша | Слоган |
|---|---|
| dental | «Стоматология, в которую возвращаются» |
| law | «Защищаем интересы — спокойно и по закону» |
| construction | «Сдаём в срок. Без переплат» |
| beauty | «Уход, который видно» |
| restaurant | «Готовим как для себя» |
| b2b | «Поставки точно в срок» |

Слоган кладётся в `brand.tagline` и часто переиспользуется как `seo.title`-хвост
или hero-eyebrow.

## 3. Логотип — векторный SVG через `scripts/gen_logo.py`

Лого делаем **вектором (SVG)**, а не через gpt-image. Причины (из docstring
скрипта): чёткость на любом размере, малый вес, отсутствие AI-артефактов, вид
«настоящей студии». Дополнительный бонус — стиль выбирается по seed, что даёт
ещё один слой непохожести сайтов (см. `anti-fingerprint.md`).

### 3.1. Что генерирует скрипт
Монограмму из **инициалов бренда** внутри геометрической формы. ViewBox
`0 0 64 64`, без `width/height` (размер задаёт CSS). Цвета — из палитры `design`.
Инициалы берутся так (функция `initials`): одно слово → первые 2 буквы; два+ слова
→ по первой букве первых двух слов; «ёлочки» `«»` отбрасываются.

> Важно: `«Дентал Люкс»` (два токена) → инициалы **ДЛ**; а `«Дентал-Люкс»`
> (через дефис, один токен) → **ДЕ**. Это влияет на монограмму — выбирай форму
> имени осознанно.

### 3.2. Восемь стилей (выбор по seed)
`STYLES = ["circle", "rounded", "outline", "split", "hexagon", "ring", "bars", "shield"]`

| Стиль | Описание | Под какую нишу |
|---|---|---|
| `circle` | сплошной круг `primary`, белые инициалы | универсал, медицина, бьюти |
| `rounded` | скруглённый квадрат `primary`, белые инициалы | b2b, IT, сервисы |
| `outline` | контур `primary` на `bg` + акцентная точка | премиум-минимал, юр., консалтинг |
| `split` | квадрат, диагональ `primary/accent`, одна буква | динамичные бренды, фитнес, авто |
| `hexagon` | шестигранник `primary` с акцентной обводкой | стройка, промышленность, логистика |
| `ring` | тонкое кольцо `primary` + акцентная точка сверху | премиум-услуги, медицина, эстетика |
| `bars` | три «столбца» (как рост/график) в рамке | b2b, аналитика, недвижимость |
| `shield` | щит `primary` + одна буква + акцентный контур | юр., безопасность, гарантии, стройка |

Выбор детерминирован: `style = STYLES[seed % 8]` при `--style auto` (дефолт).
Если seed не передан — берётся `sha256(name)[:8]` как число. Соответствие
seed→стиль (по факту скрипта): `0→circle, 1→rounded, 2→outline, 3→split,
4→hexagon, 5→ring, 6→bars, 7→shield`, далее цикл.

### 3.3. Вызов
```bash
python3 scripts/gen_logo.py \
  --name '<Бренд>' \
  --primary <hex> --accent <hex> \
  --seed N \
  --out public/images/logo.svg \
  --favicon public/icon.svg
```
Полный пример для «Дентал Люкс» (палитра из `design`):
```bash
python3 scripts/gen_logo.py --name 'Дентал Люкс' \
  --primary '#0B3D2E' --accent '#C8A24B' --bg '#FFFFFF' \
  --seed 7 --out public/images/logo.svg --favicon public/icon.svg
# → seed 7 → стиль shield → щит с буквой «Д»
```
Флаги: `--primary` (форма), `--accent` (детали/обводка/точка), `--bg`
(фон для `outline`/`bars`, по умолчанию `#FFFFFF`), `--seed`, `--style`
(`auto`|конкретный), `--serif` (засечный шрифт инициалов — под luxury/юр./editorial),
`--out` (обязателен), `--favicon` (опционально — пишет тот же SVG второй копией).

### 3.4. Выбор стиля под нишу
Хотя дефолт — `auto` (по seed, ради непохожести), стиль можно зафиксировать через
`--style`, если нужно усилить смысл (логика brandkit «symbol logic by category»):
- **юр./безопасность/гарантии** → `shield` (защита, надёжность) либо `outline` (строгий минимал) + `--serif`;
- **luxury/бьюти/премиум-медицина** → `ring` или `outline` + `--serif` (тонкость, ритуал);
- **стройка/логистика/пром** → `hexagon` или `bars` (конструкция, опора, рост);
- **IT/сервис/b2b** → `rounded` (нейтральный современный квадрат);
- **фитнес/авто/динамика** → `split` (диагональ, движение);
- **универсал/медицина** → `circle`.

Принцип brandkit: symbol logic должен совпадать со смыслом бренда, не выбираться
случайно. Но для масштаба и непохожести по умолчанию доверяем seed.

## 4. Производные: favicon и og

- **Favicon.** Передаётся флагом `--favicon public/icon.svg`: скрипт пишет ту же
  SVG-монограмму второй копией. SVG-favicon отлично масштабируется в табе и не
  требует PNG-набора. Подключается в `<head>` как
  `<link rel="icon" href="/icon.svg" type="image/svg+xml">`.
- **OG-картинка (og).** Это **не** про gen_logo. OG генерируется отдельно через
  gen_images (см. `art-direction.md`, slug `og`, размер `1536x1024`), палитра — та же
  `design.palette`. На OG лого может появиться как векторный оверлей, но фон/сцена —
  арт-дирекшн-картинка, без текста-слопа.
- **Лого в `site.images`.** Путь логотипа кладётся в `images.logo`. Лого — SVG
  (`/images/logo.svg`); если в `site.json` указан `/images/logo.png`, держим SVG
  как основной и допускаем PNG-фолбэк (см. `nextjs-build.md`, нативный `<img>` со
  svg/webp-фолбэком). Header и footer берут лого из `site.images.logo`.

## 5. Как бренд ложится в `site.json` → `brand{}`

Контракт `brand` (из `pipeline.md`, типы `lib/types.ts`):
```jsonc
"brand": {
  "name":      "Дентал Люкс",            // отображаемое имя (из §1) — в header/footer/SEO
  "legalName": "ООО «Дентал Люкс»",      // юр. форма; «ёлочки» обязательны в РУ
  "tagline":   "Стоматология, в которую возвращаются", // слоган из §2
  "slug":      "dental-lyuks",           // latin-kebab: транслит name, для путей/домена
  "domain":    "dental-lyuks.ru"         // исходный/целевой домен
}
```
Правила заполнения:
- `name` — результат §1 (РУ, с пробелами/дефисами как у вывески).
- `legalName` — `name`, обёрнутое в орг-форму: `ООО «<name>»` (по умолчанию ООО;
  для частной практики юриста/врача допустимо `ИП <Фамилия>`). Кавычки-ёлочки.
- `tagline` — слоган из §2 (проходит анти-буллшит из `copywriting.md`).
- `slug` — латинская kebab-транслитерация `name` (`Дентал Люкс` → `dental-lyuks`);
  используется в путях вывода `<output>/<brand-slug>/` и как основа домена.
- `domain` — исходный домен брифа (или `<slug>.ru`).

Связи с остальным `site.json`:
- `design.palette.primary/accent/bg` → те же hex идут в `gen_logo.py` (единая палитра
  бренда и лого).
- `seo.title` обычно = `«<name> — <оффер> в <Город>»`; `tagline` может стать хвостом.
- `images.logo` ← результат `gen_logo`; favicon ← `public/icon.svg`.
- `legalName` дублируется в реквизитах `company` (ru_data.py) и в `footer`/`contacts`.

### Чек-лист бренд-блока
- [ ] `name` — правдоподобная РУ-вывеска, не из банлиста §1.3.
- [ ] `tagline` — конкретный, без буллшита, ≤6 слов.
- [ ] `slug` — валидный latin-kebab, совпадает с папкой вывода.
- [ ] Лого сгенерировано (`logo.svg` + `icon.svg`), цвета = `design.palette`.
- [ ] Стиль лого осмыслен под нишу (или явно отдан seed ради непохожести).
- [ ] Инициалы в монограмме читаются (проверь форму имени: «Дентал Люкс»=ДЛ vs «Дентал-Люкс»=ДЕ).
- [ ] Нигде в бренде нет слов демо/тест/placeholder (правило `prop-site.md`).
