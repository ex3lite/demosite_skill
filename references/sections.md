# sections.md — каталог секций demosite

Дополнение к `references/pipeline.md` (читай его разделы **2 «Каталог секций»** и
**7 «Вариативность»**, особенно **7.7 «Реализованные варианты секций»**). Здесь — гайд по
каждому типу секции: **назначение**, **когда включать**, **полные пропсы с примерами**,
**список реализованных вариантов** (ключи берёт `variation_engine.py`, реализуют
компоненты `templates/components/sections/*`), и **как скилл заполняет пропсы** из вывода
`ru_data.py` + копирайтинга. В конце — три рекомендованных порядка секций по цели.

## Как это устроено в целом

- Каждая секция в `site.json` — объект `{ "type": "<имя>", "id": "<якорь>", ...props }`.
  `page.tsx` рендерит массив `sections` строго по порядку (см. pipeline §1).
- `type` ↔ файл `components/sections/<Type>.tsx`, принимающий `props` + `site`.
- Поле `image` в пропсах — это **slug** из `site.images` (напр. `"hero"` → `/images/hero.webp`),
  а не путь. Расширение определяется при `gen_images` (webp/png) или `.svg` при fallback.
- **Вариант** секции компонент читает из `site.variation.sectionVariants[type]` (хелпер
  `variantOf('<type>','<default>')`). Неизвестный/отсутствующий вариант → берётся **первый из пула**
  (fallback, pipeline §7.7). Каждая секция-компонент ОБЯЗАНА реализовать все свои варианты.
- **Источники наполнения пропсов:**
  - `variation_engine.py` → `design`, `variation` (включая `sectionVariants`, `heroVariant`),
    `brand`, `sections_order` (порядок и состав).
  - `ru_data.py` → фактура: `company`, `contacts`, `schedule`, `stats`, `team[]`,
    `services[]`, `reviews[]`. Эти объекты кладутся в `site.*` без изменений, а секции читают их.
  - **Копирайтинг** (см. `references/copywriting.md`) → заголовки секций (`title`/`subtitle`),
    `eyebrow`, `body[]` для about, тексты CTA, FAQ-пары, eyebrow/буллеты hero.
  - `gen_images` / `gen_logo` → `site.images` (slug → путь); секции ссылаются по slug.

## Типы секций

### `header` — липкая шапка
**Назначение:** логотип, навигация-якоря, телефон, основная CTA-кнопка.
**Когда включать:** ВСЕГДА и ПЕРВЫМ. Часть обязательного каркаса `header → hero → … → contacts → footer`.
**Пропсы:** `nav[]`, `cta`, `phone` — всё из `site` (`site.nav`, `site.cta.primary`, `site.contacts.phone`).
```jsonc
{ "type": "header", "id": "top" }
```
**Варианты:** в пуле движка отдельных вариантов нет (`header` не входит в `SECTION_VARIANTS`); шапка одна, но визуально зависит от `design` (палитра/радиус/тень/шрифты).
**Чем заполняет скилл:** `nav` собирается из реально присутствующих секций (label из копирайта, `href="#<id>"`); `phone` = `contacts.phone`; CTA = `site.cta.primary` (напр. «Записаться» → `#contacts`).

### `hero` — первый экран
**Назначение:** оффер, главный заголовок, подзаголовок, CTA, ключевой визуал/цифры.
**Когда включать:** ВСЕГДА, сразу после header. Это лицо страницы.
**Пропсы:** `variant`, `eyebrow?`, `title`, `subtitle`, `bullets?[]`, `cta`, `secondaryCta?`, `image`, `stats?[]`.
```jsonc
{ "type": "hero", "id": "hero", "variant": "split-left",
  "eyebrow": "Стоматология в Москве",
  "title": "Лечим так, чтобы вы возвращались только на профилактику",
  "subtitle": "Имплантация и реставрация под ключ за один визит. Гарантия 3 года.",
  "bullets": ["Цифровая диагностика", "Без боли и навязывания", "Рассрочка 0%"],
  "cta": { "label": "Записаться на приём", "href": "#contacts" },
  "secondaryCta": { "label": "Перезвоните мне", "href": "#contacts" },
  "image": "hero",
  "stats": [ { "value": "15", "label": "лет на рынке" }, { "value": "12 000", "label": "пациентов" } ] }
```
**Реализованные варианты** (пул `HERO`): `split-left` — текст слева, картинка справа; `split-right` — зеркально; `bg-image` — фон-картинка с текстом поверх (нужно негативное пространство под заголовок); `centered` — центрированный текст без боковой картинки.
**Чем заполняет скилл:** `variant` = `variation.heroVariant`; `title/subtitle/eyebrow/bullets` — копирайт по формулам H1 (см. copywriting); `cta` = `site.cta.primary`, `secondaryCta` из `site.cta.phoneLabel`; `image` = slug `"hero"`; `stats` — из `stats` (years_on_market, clients, rating).

### `trustbar` — полоса доверия
**Назначение:** лицензии, гарантии, года на рынке, документы — снять первичные возражения.
**Когда включать:** почти всегда после hero (часть `CORE_OPENING`). Особенно для медицины/юр/стройки, где важны лицензии.
**Пропсы:** `items[]: {icon, label, value?}`.
```jsonc
{ "type": "trustbar", "id": "trust", "items": [
  { "icon": "shield", "label": "Лицензия Росздравнадзора", "value": "№ ЛО-77-…" },
  { "icon": "award", "label": "На рынке", "value": "15 лет" },
  { "icon": "star", "label": "Рейтинг", "value": "4.9" } ] }
```
**Реализованные варианты:** `row` — статичная строка иконок-фактов; `marquee` — бегущая лента (подходит для логотипов партнёров); `stat-strip` — крупные цифры-метрики.
**Чем заполняет скилл:** `value` из `stats` (years_on_market, rating, clients) и `company` (лицензии/реквизиты); иконки — из набора `ui/Icon`. На `marquee` хорошо ложатся `Marquee` + логотипы/«работаем с».

### `services` — услуги с ценами
**Назначение:** перечень услуг, что входит, ориентир по цене.
**Когда включать:** почти всегда; обычно первый блок середины. Ядро лидгена.
**Пропсы:** `title`, `subtitle?`, `items[]: {title, desc, price_label, icon, image?, popular?}`, `layout?` (`grid`|`bento`).
```jsonc
{ "type": "services", "id": "services", "title": "Услуги и цены",
  "items": [
    { "title": "Имплантация", "desc": "Установка импланта под ключ с коронкой.",
      "price_label": "от 35 000 ₽", "icon": "tooth", "popular": true },
    { "title": "Гигиена и чистка", "desc": "Ультразвук + Air Flow за один визит.",
      "price_label": "от 4 500 ₽", "icon": "sparkle" } ] }
```
**Реализованные варианты:** `cards` — карточки в сетке; `list` — компактный список-строки с ценой; `bento` — крупно-мелкая мозаика (акцент на популярных).
**Чем заполняет скилл:** напрямую из `services[]` (`ru_data.py make_services`): `title`, `desc`, `price_label` (форматированное «от N ₽»), `icon`, `image_slug`→`image`, `popular`. Заголовок секции — копирайт.

### `features` — «почему мы» / преимущества
**Назначение:** УТП, преимущества, причины выбрать.
**Когда включать:** часто, рядом с services/about; усиливает оффер фактами.
**Пропсы:** `title`, `items[]: {icon, title, desc}`, `image?`.
```jsonc
{ "type": "features", "id": "features", "title": "Почему выбирают нас",
  "items": [
    { "icon": "scan", "title": "Цифровой протокол", "desc": "3D-снимок и план лечения сразу." },
    { "icon": "clock", "title": "Без ожидания", "desc": "Приём минута в минуту по записи." } ] }
```
**Реализованные варианты:** `grid` — равномерная сетка преимуществ; `split-image` — список преимуществ + картинка сбоку (использует `image`); `rows` — горизонтальные строки с крупными иконками.
**Чем заполняет скилл:** `items` — копирайт по нише (конкретика, без штампов «индивидуальный подход»); `image` (для `split-image`) = slug релевантной картинки (about/service).

### `about` — о компании
**Назначение:** история, факты, цифры, врезка реквизитов — социальное доказательство и реализм.
**Когда включать:** почти всегда. Хорошо снимает недоверие к «новому» сайту.
**Пропсы:** `title`, `body[]` (абзацы), `stats[]: {value, label}`, `image`, `showRequisites?`.
```jsonc
{ "type": "about", "id": "about", "title": "О клинике",
  "body": ["Работаем с 2010 года…", "Команда из 9 врачей…"],
  "stats": [ { "value": "15", "label": "лет практики" }, { "value": "9", "label": "врачей" } ],
  "image": "about", "showRequisites": true }
```
**Реализованные варианты:** `split` — текст + картинка в две колонки; `stacked` — текст над/под картинкой по центру; `side-stats` — текст + колонка крупных цифр.
**Чем заполняет скилл:** `body[]` — копирайт (история + факты, опираясь на `company.founded_year`); `stats` — из `stats`/`company`; `showRequisites` тянет краткие реквизиты из `company` (ИНН/ОГРН) для реализма; `image` = slug `"about"`.

### `process` — этапы работы
**Назначение:** шаги «как мы работаем» 1→N — снижает тревогу, показывает прозрачность.
**Когда включать:** услуги/стройка/юр/авто, где важна процедура. Опциональный (движок может убрать).
**Пропсы:** `title`, `steps[]: {n, title, desc}`.
```jsonc
{ "type": "process", "id": "process", "title": "Как мы работаем",
  "steps": [
    { "n": 1, "title": "Консультация", "desc": "Осмотр и план лечения." },
    { "n": 2, "title": "Диагностика", "desc": "3D-снимок, согласование сметы." },
    { "n": 3, "title": "Лечение", "desc": "Точно по плану и срокам." } ] }
```
**Реализованные варианты:** `stepper` — горизонтальный степпер с номерами; `vertical` — вертикальный таймлайн; `cards` — карточки-этапы.
**Чем заполняет скилл:** `steps` — копирайт по нише (типовой путь клиента); номера проставляются автоматически.

### `portfolio` — кейсы/работы
**Назначение:** галерея результатов, «до/после», объекты — визуальное доказательство.
**Когда включать:** где результат виден глазом (стройка, бьюти, ресторан-блюда, ремонт). Опциональный.
**Пропсы:** `title`, `items[]: {title, tag?, image, result?}`.
```jsonc
{ "type": "portfolio", "id": "portfolio", "title": "Наши работы",
  "items": [
    { "title": "Ремонт квартиры 64 м²", "tag": "Под ключ", "image": "portfolio-1",
      "result": "Сдано за 45 дней" } ] }
```
**Реализованные варианты:** `grid` — равная сетка; `masonry` — мозаика разной высоты; `overlay` — карточки с текстом поверх изображения по ховеру.
**Чем заполняет скилл:** `items` — копирайт (название кейса, тег, результат); `image` = slug кейсовой картинки (`portfolio-N`). `ru_data.py` фактуру кейсов напрямую не даёт — наполняется копирайтом + картинками.

### `pricing` — тарифы/пакеты
**Назначение:** пакеты услуг с фиксированной ценой и списком включённого.
**Когда включать:** где есть пакетирование (фитнес, абонементы, обслуживание, образование). Опциональный.
**Пропсы:** `title`, `plans[]: {name, price_label, period?, features[], popular?, cta}`.
```jsonc
{ "type": "pricing", "id": "pricing", "title": "Абонементы",
  "plans": [
    { "name": "Старт", "price_label": "2 900 ₽", "period": "/мес",
      "features": ["Зал", "1 групповая тренировка"], "cta": { "label": "Выбрать", "href": "#contacts" } },
    { "name": "Оптимум", "price_label": "4 900 ₽", "period": "/мес", "popular": true,
      "features": ["Зал", "Все групповые", "Сауна"], "cta": { "label": "Выбрать", "href": "#contacts" } } ] }
```
**Реализованные варианты:** `cards` — карточки-тарифы; `table` — сравнительная таблица; `highlight` — один выделенный «популярный» тариф рядом с остальными.
**Чем заполняет скилл:** `plans` собираются из части `services[]` (цены из `price_label`) и копирайта (имена пакетов, состав `features`); `popular` — флаг из услуг; `cta` ведёт на `#contacts`.

### `team` — команда
**Назначение:** лица специалистов, должности, опыт — доверие через людей.
**Когда включать:** где важна экспертиза человека (медицина, юр, бьюти, образование). Опциональный.
**Пропсы:** `title`, `members[]: {name, position, experience_years, image}`.
```jsonc
{ "type": "team", "id": "team", "title": "Наши врачи",
  "members": [
    { "name": "Анна Морозова", "position": "Главный врач, ортопед",
      "experience_years": 18, "image": "team-1" } ] }
```
**Реализованные варианты:** `grid` — сетка карточек-портретов; `cards` — крупные карточки с описанием; `row` — горизонтальная лента.
**Чем заполняет скилл:** напрямую из `team[]` (`ru_data.py make_team`): `name`, `position` (из `roles` пресета), `experience_years`, `photo_slug`→`image`. Фото — портреты «studio headshot» (см. art-direction), славянская внешность.

### `reviews` — отзывы
**Назначение:** живые отзывы клиентов + агрегированный рейтинг.
**Когда включать:** почти всегда (часто завершает середину перед FAQ/CTA).
**Пропсы:** `title`, `items[]: {author, rating, date, text, avatar?}`, `aggregate?: {rating, count}`.
```jsonc
{ "type": "reviews", "id": "reviews", "title": "Отзывы пациентов",
  "items": [
    { "author": "Мария К.", "rating": 5, "date": "2025-09-12",
      "text": "Сделали имплант за один визит, без боли. Спасибо!", "avatar": "avatar-1" } ],
  "aggregate": { "rating": 4.9, "count": 389 } }
```
**Реализованные варианты:** `grid` — сетка карточек; `slider` — карусель отзывов; `feature` — один крупный отзыв в фокусе + остальные мельче.
**Чем заполняет скилл:** напрямую из `reviews[]` (`ru_data.py make_reviews`): `author`, `rating`, `date`, `text`, `avatar_slug`→`avatar`. `aggregate` = `{rating: stats.rating, count: stats.reviews_count}`. Тексты отзывов — из пресета (`review_snippets`) или копирайта (живые, разной длины).

### `faq` — частые вопросы
**Назначение:** аккордеон реальных вопросов-возражений.
**Когда включать:** почти всегда (часть `CORE_CLOSING`). Закрывает оставшиеся сомнения перед CTA.
**Пропсы:** `title`, `items[]: {q, a}`.
```jsonc
{ "type": "faq", "id": "faq", "title": "Частые вопросы",
  "items": [
    { "q": "Есть ли рассрочка?", "a": "Да, 0% на срок до 12 месяцев без переплат." },
    { "q": "Сколько длится приём?", "a": "Первичная консультация — около 40 минут." } ] }
```
**Реализованные варианты:** `accordion` — классический раскрывающийся список; `two-col` — вопросы в две колонки; `bordered` — список с разделителями-рамками.
**Чем заполняет скилл:** `items` — копирайт по нише (реальные вопросы про цены, сроки, гарантии, безопасность).

### `cta` — финальный призыв + мини-форма
**Назначение:** последний толчок к действию + короткая форма заявки.
**Когда включать:** почти всегда перед contacts (часть `CORE_CLOSING`).
**Пропсы:** `title`, `subtitle?`, `cta`, `image?`, `variant?` (`band`|`split`|`card`).
```jsonc
{ "type": "cta", "id": "cta", "title": "Запишитесь на бесплатную консультацию",
  "subtitle": "Перезвоним в течение 15 минут и подберём удобное время.",
  "cta": { "label": "Оставить заявку", "href": "#contacts" }, "variant": "band" }
```
**Реализованные варианты:** `band` — широкая цветная полоса с призывом; `split` — текст + форма/картинка в две колонки; `card` — выделенная карточка по центру.
**Чем заполняет скилл:** `title/subtitle` — копирайт (конкретное действие, без воды); форма работает по prop-site правилам: `preventDefault` + локальная валидация + инлайн success «Заявка принята, перезвоним в течение 15 минут» (НИКАКИХ `fetch`/`action`); `cta` ведёт на `#contacts`.

### `contacts` — контакты, карта, реквизиты
**Назначение:** адрес, телефоны, график, карта, реквизиты — финальный реализм и точка конверсии.
**Когда включать:** ВСЕГДА, предпоследней (перед footer).
**Пропсы:** `title`, `map` (lat/lon/zoom), `requisites` (из company), `schedule`, `contacts`.
```jsonc
{ "type": "contacts", "id": "contacts", "title": "Контакты",
  "map": { "lat": 55.7558, "lon": 37.6173, "zoom": 15 },
  "schedule": { "weekdays": "Пн–Пт: 09:00–20:00", "saturday": "Сб: 10:00–18:00", "sunday": "Вс: выходной" } }
```
**Реализованные варианты:** `split-map` — контакты слева, карта справа; `map-top` — карта сверху, реквизиты под ней; `cards` — контакты в виде карточек (адрес/телефон/график).
**Чем заполняет скилл:** `contacts` = `site.contacts` (телефон, email, адрес, мессенджеры); `map` = `contacts.map` (координаты города по умолчанию Москва, см. `ru_data.py CITY_COORDS`); `schedule` = `site.schedule`; `requisites` из `company` (ИНН/ОГРН/КПП/банк). Карта — OpenStreetMap embed по lat/lon без ключа.

### `footer` — подвал
**Назначение:** меню-якоря, краткие реквизиты, копирайт, служебные ссылки.
**Когда включать:** ВСЕГДА и ПОСЛЕДНИМ.
**Пропсы:** собирается из `site` (nav, brand, company, legal).
```jsonc
{ "type": "footer", "id": "footer" }
```
**Варианты:** отдельных вариантов в пуле движка нет; внешний вид зависит от `design`.
**Чем заполняет скилл:** меню = `site.nav`; реквизиты кратко из `company` (legalName, ИНН/ОГРН); `legal.copyright`/служебные ссылки. ВАЖНО: НИКАКОГО дисклеймера «демо/тест/заглушка» (pipeline §7.3, §7.4); служебные ссылки (политика) на `#` с `data-no-scroll`.

## Рекомендованные порядки секций

Общее правило (pipeline §7, `variation_engine.py`): **`header` первым, `footer` последним**.
Каркас фиксирован — `CORE_OPENING = [header, hero, trustbar]`, `CORE_CLOSING = [faq, cta, contacts, footer]`.
**Середину** (`MIDDLE_POOL`) подбирает и варьирует `variation_engine` по `INDUSTRY_MIDDLE[industry]`:
делает локальную перестановку соседних блоков (шанс 50%) и может убрать 0–1 опциональный блок
(`portfolio`/`pricing`/`team`/`process`, шанс 40%). Ниже — типовые цели и опорные раскладки.

### (a) Лидген-услуги (клиника, юрфирма, ремонт)
Цель — заявка. Бьём по доверию (лицензии, процесс, команда, отзывы), ведём к форме.
```
header → hero → trustbar → services → features → about → process → team → reviews → faq → cta → contacts → footer
```
Опора движка: `dental`/`clinic`/`law` (`services, features, about, process, team, reviews`).
Ключевое: `trustbar` сразу после hero; `process` снимает тревогу; `faq` гасит возражения перед `cta`.

### (b) Витрина / портфолио (стройка, бьюти, ресторан)
Цель — показать результат глазами. Акцент на `portfolio`, визуал важнее текста.
```
header → hero → trustbar → services → portfolio → about → process → reviews → faq → cta → contacts → footer
```
Опора движка: `construction`/`beauty`/`restaurant` (в середине рано идёт `portfolio`).
Ключевое: `portfolio` высоко (после services); hero лучше `bg-image`/`split`; team опционален.

### (c) B2B / презентация
Цель — донести выгоду и цифры лицу, принимающему решение. Сдержанно, фактологично.
```
header → hero → trustbar → services → features → about → process → reviews → faq → cta → contacts → footer
```
Опора движка: `b2b`/`logistics` (`services, features, about, process, reviews`).
Ключевое: упор на `features` (выгода+цифры) и `about` (факты/опыт); `pricing` обычно не нужен;
`trustbar` как `marquee` логотипов клиентов работает на доверие.

> Эти раскладки — ориентиры. Реальный порядок для конкретного домена выдаёт
> `variation_engine.py` в `sections_order` (он же определяет состав середины и `sectionVariants`).
> Скилл собирает `site.sections[]` именно из `sections_order`, проставляя каждому элементу
> `type`/`id` и пропсы из `ru_data.py` + копирайтинга, а вариант — из `variation.sectionVariants[type]`.
