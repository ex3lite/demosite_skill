# demosite

Автономный навык (Claude Code skill) для генерации **премиальных одностраничных сайтов-витрин**
для бизнеса (РФ-контекст). На вход — **домен и короткое описание**, на выходе — готовый,
наполненный данными Next.js + React + Tailwind лендинг.

```
/demosite dental-lux.ru — премиальная стоматология в Казани
```

## Что делает

- **Бренд и дизайн-система** из домена/описания, с собственным **движком вариативности**, который
  по домену/seed детерминированно подбирает палитру, режим (light/dark), пару шрифтов, радиусы,
  тени, ширину, вертикальный ритм, варианты каждой секции и порядок секций — так, что **два сайта
  структурно не похожи** и по набору сайтов не вычисляется общий шаблон.
- **Валидные РФ-реквизиты** (ИНН/ОГРН/ОГРНИП/КПП/СНИЛС/расчётный счёт) — проходят **настоящие
  контрольные суммы** (алгоритмы ЦБ РФ и ФНС). Данные синтетические (случайные), не принадлежат
  реальным организациям; это наполнение для реализма витрины.
- **Контент**: услуги с ценами ₽, команда (ФИО, стаж), отзывы, FAQ, график, адрес, карта
  (OpenStreetMap, без ключа). Живой РУ-копирайт без буллшита и без маркеров «демо».
- **Картинки**: одна арт-дирекшн-картинка на секцию через OpenAI **gpt-image-1.5** (люди —
  славянская внешность, контекст РФ, без текста на фото). Без ключа — premium SVG-плейсхолдеры.
  Логотип — рукописный векторный SVG (несколько стилей).
- **Лоадер и анимации** (по принципам Emil Kowalski): preloader, появление по скроллу со
  stagger, счётчики, marquee, hover-микроинтеракции; всё на `transform/opacity` и с уважением
  к `prefers-reduced-motion`.

## Назначение

Сайты — **самодостаточные витрины (бутафория) перед собственным бэкендом**: одна страница,
**чистый URL без саб-роутов**, формы работают на вид (локальный success, без сетевых запросов),
никаких следов «демо/тест/заглушка». Это типовой приём анти-цензурного камуфляжа: перед личным
сервисом (например, FastAPI-бэкендом) ставится правдоподобный сайт обычного бизнеса.

> **Ответственность.** Данные синтетические и не имитируют конкретную реальную организацию.
> Используйте навык законно: для камуфляжа собственной инфраструктуры, демонстраций, прототипов.
> Не для выдачи себя за чужую компанию или введения людей в заблуждение.

## Архитектура

Каждый сгенерированный проект — **data-driven**: весь сайт рендерится из `data/site.json`, код
компонентов не меняется от сайта к сайту — меняются только данные и картинки.

```
scripts/
  variation_engine.py  # дизайн+структура по домену/seed (анти-фингерпринт)
  ru_data.py           # РФ-реквизиты и контент (валидные контрольные суммы; --selftest)
  gen_images.py        # батч gpt-image-1.5 + SVG-fallback
  gen_logo.py          # рукописный SVG-логотип (стили по seed)
  credentials.py       # ключ вне репозитория (~/.config/demosite/.env)
  scaffold.sh          # детерминированный скаффолд Next.js
templates/             # фундамент проекта + библиотека секций (Next.js 15, React 19, Tailwind v4)
references/            # пайплайн, арт-дирекшн, копирайтинг, анимации, prop-site, QA, …
data/industries.json   # пресеты ниш
vendor/ui-ux-pro-max/  # дизайн-движок (палитры, типографика, стили)
SKILL.md               # оркестратор
```

## Ключ OpenAI

Не хранится в репозитории. Резолв: переменная `OPENAI_API_KEY` → `~/.config/demosite/.env`
(права 600). Навык спрашивает ключ при первом запуске и сохраняет его туда. Без ключа сайт
собирается с SVG-плейсхолдерами.
